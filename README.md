# Central de Utilidades

Aplicação Web desenvolvida por **Kezia Manuella** para a disciplina de **Programação Web I** (IF Sudeste MG — Campus Barbacena, Prof. Fábio Ferreira), reunindo ferramentas práticas para cálculos do dia a dia.

## Acesso ao Projeto

- **Página publicada:** https://kezia242.github.io/central-de-utilidades/

## Funcionalidades

- **Calculadora de Descontos:** calcula o valor economizado e o preço final de um produto com base no preço original e no percentual de desconto.
- **Calculadora de Parcelas:** calcula o valor de cada parcela de uma compra sem juros.
- **Simulador de Investimentos:** simula a evolução do saldo ao longo dos meses considerando investimento inicial, aportes mensais e taxa de rendimento mensal.
- **Divisor de Despesas:** permite cadastrar despesas com descrição e valor, remover itens, calcular o total e dividir o valor entre os participantes.

## Estrutura do Projeto

- `index.html`: estrutura da página e formulários.
- `style.css`: estilização visual e layout responsivo.
- `script.js`: lógica das funcionalidades, validações e manipulação da interface.
- `esboco-interfaces.png`: esboço inicial da organização das quatro ferramentas.

## Como Visualizar

Você pode abrir o arquivo `index.html` diretamente no navegador ou acessar pelo link publicado acima.
